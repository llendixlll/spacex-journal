# Журнал космічних запусків

Консольний застосунок на Dart для дисципліни «Кросплатформенне програмування».
Варіант 12 — журнал космічних запусків (предметна область SpaceX).

## Що вміє

- показує список запусків;
- додає новий запуск;
- видаляє запуск за номером у списку;
- зберігає дані у локальному файлі `data.json` і відновлює їх під час наступного запуску.

Дані про кожен запуск: номер польоту, назва місії, рік, ракета, ознака успіху.

## Як запустити

```bash
dart pub get
dart run bin/main.dart
```

Під час роботи програма читає та перезаписує файл `data.json` у корені проєкту.

## Рівень виконання

Роботу виконано на рівень **«задовільно»**: одна модель предметної області,
текстове меню (показати / додати / видалити / вихід), серіалізація
`toJson()` / `fromJson()`, збереження та відновлення даних із файлу
`data.json`, стійкість до некоректного вводу.

Рівень **«добре»** додатково вимагає отримання даних із зовнішнього
SpaceX API v4 через пакет `http`. На момент виконання роботи цей сервіс
недоступний: запит до `https://api.spacexdata.com/v4/launches` повертає
помилку **HTTP 525 (SSL handshake failed)** на боці Cloudflare/SpaceX,
тож отримати реальні дані з API не вдалося. Відповідно до вимог, за
недоступності сервісу застосунок коректно продовжує працювати з
локальними даними у файлі `data.json`.

## Використане API

Варіант передбачає предметну область SpaceX API v4
(`https://api.spacexdata.com/v4/launches/latest`). На поточному рівні
застосунок працює з локальним файлом `data.json`; отримання даних із
зовнішнього API — наступний етап роботи.
